# ERP 현대화 기능·화면 매트릭스

- 작성일: 2026-07-12
- 목적: 현대적 전면 개편과 React 전환 과정에서 현재 기능이 누락되지 않도록 화면, 작업, 권한, 출력, 모바일 동작을 기준선으로 고정한다.
- 판정 기준: 단순히 버튼이 보이는 것이 아니라 기존 데이터 결과와 후속 업무 연결까지 동일해야 기능이 보존된 것으로 본다.
- 주요 근거: `src/html/pages`, `src/js`, `src/react/src`, `BULK_CFG`, `PAGE_LIST`, `FEATURE_DEFS`.

## 현대화 기준 구조

- 기본 방향은 시안 2의 `전역 아이콘 레일 + 업무별 보조 메뉴 + 데이터 작업면 + 우측 인스펙터` 구조를 사용한다.
- 시안 3의 `오늘 처리`, 지연·부분완료 그룹, 상태 진행선을 결합한다.
- 전역 메뉴는 `홈`, `영업`, `구매`, `생산`, `재고`, `품질`, `재무`, `기준정보`, `시스템`으로 제한한다.
- 업무별 보조 메뉴에 하위 화면, 저장 보기, 예외 보기, 최근 작업을 배치한다.
- 목록은 표를 기본으로 유지하고 선택 체크박스, 핵심 식별 열, 숫자 열, 상태 열을 공통 규칙으로 만든다.
- 우측 인스펙터는 `개요`, `품목/연결`, `이력`을 기본 탭으로 하고 업무에 따라 결재, 첨부, 문서 탭을 추가한다.
- 등록·수정은 단건 드로어와 다중 품목 확장 드로어를 구분한다.
- 모바일은 데스크톱 작업바를 숨기는 방식이 아니라 별도 하단 내비게이션, 선택 작업 메뉴, 전체 화면 폼을 렌더한다.

## 전 화면 공통 기능

| 영역 | 현재 기능 | 현대화 보존 기준 |
|---|---|---|
| 내비게이션 | 좌측 메뉴, 상단 메뉴, 뒤로/홈, 모바일 전체 메뉴, 최근 화면 복원 | 전역 레일과 업무별 메뉴로 재구성하되 모든 페이지 경로와 뒤로가기 상태를 보존 |
| 검색 | 전역 검색, 화면별 검색, 고객사·제품·거래처 돋보기 검색 | 입력 제안, 전체 검색 팝업, 신규 거래처/고객사 등록 진입을 키보드와 마우스로 제공 |
| 필터 | 고객사·제품·상태·기간·보기 필터 | 필터 순서를 표준화하고 저장 보기, 초기화, 적용 건수를 제공 |
| 표 | 정렬, 열 표시 설정, 열 숨김 권한, 내부 가로 스크롤, 고정 선택 열 | 공통 `DataTable`에서 정렬·열 너비·표시·고정·빈 상태·로딩 상태를 제공 |
| 선택 | 체크박스, 전체 선택, 행 재클릭 해제, 모바일 선택바 | 선택 건수, 단건/다건 작업 차이, 현재 필터 범위의 전체 선택 여부를 명확히 표시 |
| 상세 | 행 선택 시 우측 상세, 상태 변경, 작업 버튼, 최근 이력, 패널 너비 저장 | `개요·연결·이력` 인스펙터와 명시적 닫기, Escape, 포커스 복귀, 반응형 전체 화면 전환 |
| 등록·수정 | 우측 등록 패널, 사이드바 이동 시 닫기, 검색 picker, 다중 품목 | 단건/다중 폭 전환, 필드 검증, 저장 중, 중복 제출 방지, 변경 내용 이탈 경고 |
| 일괄 작업 | 수정, 복제, 완료, 입고완료, 발주서 생성, 삭제, 해제 | 선택 작업바에 대표 작업 1개와 더보기 메뉴를 사용하고 영향 건수 확인창 제공 |
| 문서 처리 | PDF, Excel, 이메일, Drive 저장, 출력 이력 | 공통 `문서 처리` 메뉴에서 형식·수신자·진행 상태·실패 재시도를 일관되게 제공 |
| 상태 | 표의 읽기 전용 pill, 상세/작업 메뉴에서 상태 변경 | 상태 전이 규칙, 역전 사유, 권한, 연관 데이터 영향을 확인한 뒤 변경 |
| 알림 | 토스트, 상단 알림, 알림 설정, 긴급/경고 필터, 직접 등록 | 성공·오류·진행 중·재시도 상태를 구분하고 중요한 실패는 알림 센터에 남김 |
| 권한 | 페이지, 열, 기능, 데이터 범위, 비용 정보, 레코드 소유권 | UI 숨김과 서버 권한을 동일한 정책으로 사용하고 권한 없음 상태를 명시적으로 표시 |
| 테마·접근성 | 밝음/어두움, 배율, 글자 크기, 표 선, 브랜드 설정 | 200% 확대, 키보드 탐색, 포커스 표시, 스크린리더 이름, 동작 줄이기 설정 지원 |

## 권한 기준

- 역할: `admin`, `manager`, `staff`.
- 페이지 권한: 역할별 허용 화면 목록.
- 기능 권한: 등록, 수정, 삭제, 복구, 승인, 상태 변경, Excel, PDF, 감사 로그.
- 열 권한: 화면별 숨김 열과 등록 버튼 표시 여부.
- 데이터 범위: 공유, 본인, 부서, 직접 공유·승인 대상.
- 비용 정보: 관리자·중간관리자만 기본 허용.
- 서버 기준: 비활성 사용자는 데이터 접근 불가, 본인 역할·활성값 변경 불가, 관리자 설정·비밀값·감사 로그 직접 위조 불가.
